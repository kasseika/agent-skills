# agent-skills

地域活性化総合研究所（地活研、[kasseika.club](https://kasseika.club)）が公開する、AIエージェント向けのスキル集です。

## 導入

```bash
npx skills add kasseika/agent-skills
```

## スキル一覧

スキルは `skills/<スキル名>/SKILL.md` に置いています。

| スキル | 内容 |
|---|---|
| [kasseika-slides](skills/kasseika-slides/SKILL.md) | 地活研名義のスライド・発表資料のブランド規約（ロゴ・色・フォント・レイアウト・出典の書き方） |
